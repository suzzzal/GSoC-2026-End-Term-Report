## INTRO

I got the opportunity to work on **AI-Powered Knowledge Assistant for Drupal** during Google Summer of Code 2026.

From exploring Drupal's AI ecosystem and RAG for the first time to building a functional knowledge assistant integrated with Drupal, these few months have been an incredible learning experience. This report summarizes my GSoC journey, the work I completed, the challenges I faced, and what I learned along the way.
